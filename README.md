# last-address-map

Сайт о жертвах политических репрессий в СССР, привязанный к конкретным адресам.
Рабочее название репозитория; публичное имя сайта ещё не выбрано.

Цели: показать масштаб; напомнить, что это могло случиться с каждым; привязать к конкретному месту на карте.
Замысел и открытые вопросы — в [docs/concept.md](docs/concept.md).

## Что уже есть

- `site/` — черновая карта Москвы: 4 584 дома, 10 839 расстрелянных жильцов, клик по дому открывает список людей.
- `data/moscow/` — база «Расстрелы в Москве» (mos.memo.ru): 5 281 адрес, 11 789 человек, координаты домов.
- `scripts/` — сборка данных.

## Как посмотреть карту

Страницу нельзя открывать двойным щелчком как файл: данные и подложка не загрузятся. Нужен веб-сервер:

```
python -m http.server 8000 -d site
```

и открыть http://localhost:8000

## Структура

```
data/moscow/      исходные csv по Москве (в git, ~6 МБ)
data/reference/   справочники: старые и новые названия улиц Москвы
data/raw/         большие сырые данные — НЕ в git, см. data/raw/README.md
geocache/         кэш геокодера (чтобы не запрашивать адреса повторно)
scripts/          build_moscow_points.py, build_victims_flat.py, geocode_leningrad.py
site/             сайт: index.html, map.js, data/, vendor/leaflet
docs/             замысел, решения, открытые вопросы
```

## Источники данных

- https://github.com/nextgis/memorial_data — машиночитаемая копия данных «Мемориала» (скачано 2026-11-19).
  Лицензия данных по README источника: «unknown, possibly CC-BY». Перед публикацией сайта это нужно уточнить.
- https://github.com/nextgis/topography-of-terror — таблица старых и новых названий улиц.
- Координаты московских домов — геокодирование Д. Скугаревского (файл из того же репозитория nextgis).
- Leaflet 1.9.4 (BSD-2-Clause) — в `site/vendor/leaflet`.

## Известные оговорки

- У 697 московских адресов (950 человек) нет координат — на карте их нет.
- Координаты привязаны к современной Москве; часть домов 1930-х снесена.
- Ленинград: геокодирование начато и остановлено на ~5% адресов, качество совпадений не проверено.
- Лицензия Apache-2.0 в корне относится к коду, а не к данным.
