# Замысел (состояние на 2026-11-20)

Это запись обсуждения, а не утверждённое ТЗ. «Решено» — сказал Илья; «предложено» — идеи, которые ему понравились, но не закреплены.

## Решено
- Форма: сайт. В конце посетитель свободно двигается по карте и открывает точки.
- «Просто карта» — скучно. Три цели: (А) масштаб, (Б) «это могло быть с каждым», (В) привязка к конкретному месту.
- Проект ведётся через git; репозиторий приватный.

## Предложено: сценарий
1. Тёмный экран, один вопрос: «Где ты живёшь?» → ближайший дом, одно имя.
2. «Твой маршрут»: дом и работа → «по дороге ты проходишь мимо N домов».
3. «Зеркало»: возраст и профессия посетителя → сколько таких же людей.
4. При приближении вместо точек — имена.
5. Отъезд камеры: улица → район → город, растущий счётчик.
6. Честный финал: «это только расстрелянные и только те, чей адрес сохранился» → свободная карта.
7. Сдержанный тон: без драматической музыки и «кровавой» эстетики, сухие факты.

## Предложено: форма
- Сайт с прокруткой (карта закреплена, прокрутка ведёт камеру и текст), один ввод адреса в начале.
- Плоская карта или наклонённая объёмная со светящимися окнами (окно = человек) — решить по прототипу одного квартала (например, Арбат).
- Сначала под телефон. Дополнения: режим прогулки с геолокацией, карточка «Моя улица» для шеринга, телеграм-бот, фильм/инсталляция из того же движка, связь с «Последним адресом».

## Идея Ильи (не решено): объёмный город
- Не плоская карта, а такая, по которой можно «погулять»: выдавленные объёмные дома, стилизованные под сталинскую Москву. Илья сам не уверен, усилит ли это опыт.
- Где объём работает: окна (одно светящееся окно = один человек; Серафимовича, 2 — 242 окна), взгляд с высоты человеческого роста, отъезд камеры с тротуара над городом.
- Риски: «игра вместо памяти» при свободной прогулке; контуры домов доступны только современные, часть домов 1930-х снесена — «сталинская Москва» будет стилизацией, и об этом надо честно написать; красивая архитектура может эстетизировать тему (предложено: тёмные серые объёмы без декора, свет только у окон); слабые телефоны.
- Компромисс: наклонённая карта с выдавленными домами, «прогулка» — пролёт камеры по маршруту без свободного управления, свободный режим только в финале.

## Физический слой и распространение
- QR-коды или печатные карты района.
- Карточка «Моя улица: N домов, M человек» — механизм, которым сайт расходится по людям.

## Ранние идеи (до выбора формы «сайт»; могут стать главами или отдельными вещами)
1. Один день: 28 февраля 1938 года — 258 расстрелянных в московской базе.
2. «Расстрелянное кино»: работники «Мосфильма», кинофабрик, Главного управления кинематографии (точное число не посчитано: поиск по «кино» цепляет посторонние слова).
3. «Это мог быть ты»: возраст, профессия, район → реальные люди с такими же данными.
4. Звук вместо картинки: один расстрел — один удар, одна секунда — один день.
5. Титры из всех 2,7 млн имён (при 2 секундах на имя — около 62 суток; расчёт, не измерение).
6. «В этот день»: бот или лента по датам (московская база покрывает 315 дней года).
7. Скульптура из данных в Houdini.
8. «Квартира»: история одной коммуналки, где расстреляли нескольких человек.

## Предложено: слои данных
- Линия от дома к месту захоронения (Бутово 5 048, Коммунарка 3 675, Донское 2 465).
- Календарь / глава «один день» (28.02.1938 — 258 человек; всего 590 дат).
- Места рождения, сходящиеся в Москву. Возраст: 16–81, медиана 43.
- 651 квартира, где расстреляно больше одного человека.
- Тюрьмы и шарашки из «Топографии террора».
- Дата реабилитации, орган и статья — требуют сшивки с общей базой (не проверено, получится ли).
- Исторический контекст (приказ № 00447, национальные операции, тройки, «10 лет без права переписки») — только после сверки с источниками.
