# Правила для работы в этом репозитории

- Язык общения и документации — русский.
- Сырые данные (data/raw/) в git не коммитить; файлы больше ~20 МБ не добавлять.
- Любая цифра или исторический факт, попадающий на сайт или в docs, должен иметь источник (файл данных + способ подсчёта или ссылка). Нет источника — пометка «не проверено».
- Это реальные люди. Не выдумывать биографии, лица, цитаты; не «дополнять» записи.
- Сначала обсуждение замысла, потом сборка. Состояние замысла — docs/concept.md; обновлять его при новых решениях.
- Проверка карты: `python -m http.server 8000 -d site` и открыть в браузере; не сообщать «работает» без проверки.
